PixelProof Companion 使用说明
===============================

系统要求
- Windows 10 或 Windows 11，64 位系统
- 已安装 Microsoft Edge 或 Google Chrome

启动
1. 请先完整解压 ZIP，不要只把 EXE 单独拖出来。
2. 双击“PixelProof Companion.exe”。
3. 启动后会出现 PixelProof 状态窗口；显示绿色状态即表示服务在线。
4. 回到 Figma 插件，点击“我已启动，重新检测”。需要停止服务时，在状态窗口点击“关闭伴侣”。

日常使用
- 关闭 Figma 不会自动退出伴侣。
- 双击任务栏托盘图标，可以重新打开状态窗口。
- 状态窗口提供重新启动、最小化到托盘和关闭伴侣按钮。
- 点窗口右上角 × 只会缩到托盘，不会停止服务。
- 右键任务栏托盘图标，也可查看状态、重启、打开日志或退出。
- 可以在托盘菜单中开启“开机自动启动”。
- 下次使用不需要重新下载，只需重新打开 PixelProof Companion.exe。

常见问题
- 插件仍显示未启动：确认没有只复制 EXE，整个文件夹必须保留；然后在托盘菜单选择“重新启动伴侣”。
- 找不到浏览器：请安装或更新 Microsoft Edge / Google Chrome。
- Windows 提示未知发布者：当前测试版尚未做商业代码签名，请确认文件来自 PixelProof 官方下载地址。

隐私
- 服务只监听本机 localhost:49321。
- 页面由本机 Edge/Chrome 打开，截图和 DOM/CSS Token 证据不会上传到第三方服务。
